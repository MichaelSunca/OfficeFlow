# OfficeFlow - 企业办公自动化管理系统 (v1.0)

OfficeFlow 是一款轻量级、响应式的企业后端管理系统，旨在简化中小型企业的资产管理、行政审批与组织架构维护。系统采用 **Spring Boot 3 + Vue 3** 的前后端分离架构，核心目标是**高效、安全、无状态**。

## 1. 核心技术栈

* **后端**: Java 21, Spring Boot 3.5+, Spring Security, JWT, MyBatis-Plus
* **数据库**: MySQL 8.0+
* **前端**: Vue 3, Vite, Element Plus / Vant UI (Mobile)
* **规范**: RESTful API, Conventional Commits, JWT Stateless Auth

---

## 2. 功能模块清单

### 2.1 基础底座 (Foundational Infrastructure)

* [x] **身份认证 (Auth)**: 基于 JWT 的无状态登录体系。
* [x] **安全防护**: 禁用 CSRF，集成 BCrypt 密码加密。
* [x] **异常处理**: 全局 @RestControllerAdvice 捕获，标准 JSON 返回格式。
* [ ] **多语言 (i18n)**: 后台支持中/日/英三语切换（规划中）。

### 2.2 资产管理 (Asset Management) —— 核心业务

* [ ] **资产台账**: 办公设备（电脑、桌椅、耗材）的入库、编号、规格记录。
* [ ] **状态追踪**: 实时查看资产状态（闲置、领用中、维修中、报废）。
* [ ] **领用归还**: 员工端发起申请，管理员端一键确认。
* [ ] **报表导出**: 支持导出 Excel/PDF 格式的资产清单。

### 2.3 员工与权限 (HR & RBAC)

* [ ] **组织架构**: 支持多级部门树状展示。
* [ ] **员工管理**: 维护员工工号、入职状态、所属部门及联系方式。
* [ ] **权限分配**: 基于角色的权限控制 (Admin / Manager / Staff)。

### 2.4 流程审批 (Workflow)

* [ ] **我的申请**: 员工查看自己发起的办公用品、申领等进度。
* [ ] **待办任务**: 管理员集中处理所有待审批事项。
* [ ] **通知提醒**: 审批状态变更后的站内消息提示。

---

## 3. 数据库逻辑结构 (ER Preview)

* **User (用户)**: 关联部门与角色。
* **Asset (资产)**: 系统的核心实体。
* **Department (部门)**: 树状逻辑父子结构。
* **Record (流转记录)**: 记录每一次领用、归还、维修的流水。
